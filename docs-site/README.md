# simple-statistics docs site

Published to https://simple-statistics.github.io/.

The landing page (`src/content/docs/index.mdx`) is hand-written, and the API
reference (`src/content/docs/api/`) is autogenerated from
documentation comments.

From the repo root:

```sh
pnpm build:docs
```

This mirrors `../src/*.js` (excluding the hand-written `.d.ts` files, which
would otherwise shadow the JSDoc TypeDoc needs) into `../.typedoc-src/`, then
runs `astro build` here, which invokes TypeDoc via the `starlight-typedoc`
plugin as part of the build.

From this directory directly:

| Command           | Action                                       |
| :----------------- | :-------------------------------------------- |
| `pnpm dev`         | Starts local dev server at `localhost:4321`   |
| `pnpm build`       | Builds the production site to `./dist/`       |
| `pnpm preview`     | Previews the build locally, before deploying  |
