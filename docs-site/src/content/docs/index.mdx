## Features

**Simple Statistics** is a JavaScript library that implements statistical
methods. It helps coders harness the power of statistics and statisticians
understand code. The library is exhaustively documented, written in a simple
and friendly style, and thoroughly tested.

## Install

You can use simple-statistics with node.js by installing it with npm.

```sh
npm install --save simple-statistics
```

The npm package is usable in node.js and the web via bundlers like
[esbuild](https://esbuild.github.io/), [webpack](https://webpack.js.org/),
or [rollup](https://rollupjs.org/).

## CDN

You can also use simple-statistics in webpages from
[unpkg](https://unpkg.com/):

```html
<script src="https://unpkg.com/simple-statistics@7/dist/simple-statistics.min.js"></script>
```
